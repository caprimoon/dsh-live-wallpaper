# LiveCanvas · 动态壁纸与毛玻璃

在 DeepSeek Harness 窗口背后铺一层动态壁纸，并把左侧栏、对话内容区与底部输入框变成三块可分别调节颜色的毛玻璃面板。壁纸、图库与全部显示设置都集中在右侧抽屉里。

## 功能

### 五源在线图库与离线内置场景

- **聚合浏览**：Mixkit（实拍 / 抽象素材）、MoeWalls、MotionBgs、WallpaperWaifu、LiveWallpapers4Free 五家片源，可跨源聚合，也可只看单一来源。
- **分类与搜索**：自然风景、人文生活、城市建筑、抽象几何、动漫、游戏、幻想科幻、像素艺术；支持英文关键词检索与分页。
- **本地媒体**：导入 256 MB 以内的 `MP4` / `WebM` / `GIF` / `PNG` / `JPG` / `WebP`，分片上传后复制到插件数据目录，不转码、不压缩；也可直接应用媒体直链。
- **离线场景**：内置「深蓝雨幕」「远航星空」「代码之雨」三个低负载 Canvas 场景，无网也能用。

### 五区毛玻璃

- 左侧栏、内容区、输入框、用量栏、指令菜单各有独立底色（默认 `#232323` / `#232323` / `#4A4A4A` / `#4A4A4A` / `#4A4A4A`）。
- 每区自带**遮罩 0%–100%** 与**玻璃模糊 0–24px**（`backdrop-filter`），无需开关，始终各自调节、互不影响。
- 你发送的消息气泡会基于对话区底色自动微调亮度，保持与回复卡片的区分。

### 画面与性能

- **画面适配**：填满整窗（按最短边等比铺满，不留黑边）、完整显示、拉伸铺满；填满模式下可调主体横向 / 纵向裁切重心。
- **视频画质**：自动 / 预览 / 1080p / 2K / 4K，原站未提供或不可用时自动回退预览。
- **播放控制**：倍速、自动轮换（优先收藏）、窗口不可见时暂停、**任务运行中暂停**（Host 侧真实信号）、尊重系统「减少动态效果」。

## 使用

1. 在 **插件** 中安装并启用本插件。
2. 左侧栏导航区出现「动态壁纸」入口（与「插件」「插件市场」「自动化任务」并列），点击展开右侧抽屉；再点一次收起。
3. 抽屉内「在线图库」挑一张点击应用；或到「显示设置」调整四区的颜色、遮罩与模糊。

## 数据与边界

- 在线图库仅在本机 Host 进程内直接请求对应视频源，缩略图经插件路由代理；本地导入的媒体只写入插件数据目录（默认 `$DSH_HOME/live-canvas/media/`，本机实测落在当前 profile 目录下，可用环境变量 `DSH_LIVE_CANVAS_DIR` 改到别处）。
- 不读取、不上传会话正文、提示词或本地代码路径；不注册任何模型工具。
